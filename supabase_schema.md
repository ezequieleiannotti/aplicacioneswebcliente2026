# Esquema de Base de Datos Supabase (E-commerce Simple)

## 1. Propuesta de Estructura y Justificación

Para mantener el proyecto lo más simple y funcional posible para la materia, **te recomiendo NO utilizar una tabla de usuarios ni el sistema de autenticación de Supabase por ahora**. 

La autenticación añade capas de complejidad (manejo de tokens, registro, login, recuperación de contraseña) que te pueden desviar del objetivo principal: hacer un CRUD (Crear, Leer, Actualizar, Borrar) de productos y comentarios.

### Estructura recomendada (2 Tablas):

1. **`productos`**: Almacena todo lo relativo a tu catálogo.
2. **`comentarios`**: Almacena las reseñas. En lugar de vincularlo a un usuario registrado, simplemente guardaremos el `nombre_usuario` como un texto (el nombre que la persona escriba al dejar el comentario).

**Relación**: **Uno a Muchos**. Un producto puede tener muchos comentarios. Usaremos una **Clave Foránea (Foreign Key)** en la tabla de comentarios que apunte al producto. Esto es fundamental para que, si borras un producto, se borren automáticamente sus comentarios (regla de integridad referencial `ON DELETE CASCADE`).

  imagen TEXT,
  categoria TEXT,
  stock INTEGER DEFAULT 0,

  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  producto_id BIGINT NOT NULL REFERENCES productos(id) ON DELETE CASCADE,
  nombre_usuario TEXT NOT NULL,
  comentario TEXT NOT NULL,
  puntuacion INTEGER CHECK (puntuacion >= 1 AND puntuacion <= 5),

);

## 3. Políticas de Seguridad (RLS - Row Level Security)

Para este entorno educativo, ejecutaremos las políticas para permitir todo de forma anónima. Así no tendrás el error al guardar productos:

```sql
-- Activar RLS en ambas tablas
ALTER TABLE productos ENABLE ROW LEVEL SECURITY;
ALTER TABLE comentarios ENABLE ROW LEVEL SECURITY;

-- Crear política para permitir TODO acceso público a productos
CREATE POLICY "Permitir acceso publico total a productos" 
ON productos FOR ALL 
USING (true) WITH CHECK (true);

-- Crear política para permitir TODO acceso público a comentarios
CREATE POLICY "Permitir acceso publico total a comentarios" 
ON comentarios FOR ALL 
USING (true) WITH CHECK (true);
```
